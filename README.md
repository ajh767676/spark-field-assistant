# 🏠 Spark Field Assistant

Spark Field Assistant is a mobile-first property inspection and repair estimating application built for the Spark Homes Developer Challenge.

The application helps acquisition specialists perform property walkthroughs, estimate repair costs, track inspection progress, generate repair summaries, and evaluate investment opportunities directly from a mobile device.

---

## Features

- 📋 Guided property inspection workflow
- 🏠 Multiple property projects
- 🚪 Interior, Kitchen, Bathroom, Systems, and Exterior inspections
- ➕ Dynamic bathroom creation
- ✅ "No Action Needed" workflow
- 💲 Automatic repair cost calculations
- 📈 Live project total
- 📊 Progress tracking
- 📝 Inspection notes
- 💾 Automatic localStorage persistence
- 📄 Professional repair summary
- 📁 CSV estimate export
- 💹 Deal Analyzer
  - Estimated Profit
  - Profit Margin
  - 70% Rule Maximum Offer

## Design Goals

The application was designed with a **mobile-first workflow** so acquisition agents can quickly complete inspections during property walkthroughs.

The interface focuses on:

- Simple navigation
- Large touch-friendly controls
- Fast repair entry
- Immediate cost visibility
- Professional estimate summaries

---

## Creative Feature

The Deal Analyzer extends the application beyond repair estimating by allowing users to evaluate investment opportunities using:

- Purchase Price
- After Repair Value (ARV)
- Repair Costs
- Selling/Holding Costs

The application calculates:

- Estimated Profit
- Profit Margin
- 70% Rule Maximum Offer
